# The same coffee system, twice

Left column is what is live on cupq.app today. Right column is the
re-imagined version on the test copy. Same event, same data, same journey —
captured on the same day, at the same window size, signed in as the same user.

The point is not that one is prettier. It is that the old one asks you to know
where things are, and the new one does not.

---

## The shape of it

**Old: four interfaces.** Landing page → pick Barista, Organiser, Support or
Display. Each one its own world, its own colours, its own idea of a menu. If
you were on the wrong one you went back to the landing page and started again.

**New: three roles.** The person making coffee, the person running the day,
and the screens. Organiser and Support were doing the same job from two doors,
so they became one runner app. A "Switch view" control in the header moves
between them without going home.

| | old | new |
| --- | --- | --- |
| Places to start | 4 | 3 |
| Getting between them | back to the landing page | one control, in the header |
| Setting up an event | Organiser, tabs across the top | Runner → **Set up** |
| Running the day | split across Organiser and Support | Runner → **Run the day** |
| Looking back | nowhere in particular | Runner → **Review & system** |

The sidebar groups are the whole argument: **Set up · Run the day · Review &
system**. That is the order a day happens in.

## What actually changed, in a sentence each

- **One place to start**, not four, and a way between them that is not the back
  button.
- **The sidebar is the day**: set up, run it, look back.
- **Settings look like settings.** An icon, a name, one line of explanation, one
  control — instead of a bare dropdown with a paragraph of grey text underneath.
- **One palette.** The old app had four interfaces each with its own colour, plus
  blues, purples, teals and greys from whoever built each screen. Areas are told
  apart by name and icon now; colour means state — ready, watch this, wrong.
- **Colour that means something keeps meaning it.** Green is ready, amber is
  watch this, red needs a person. Milk colours on an order card are the
  operator's own and were not touched.
- **The report is real.** It covers the event you actually ran, in your own
  timezone, and says how much coffee and milk it took.
