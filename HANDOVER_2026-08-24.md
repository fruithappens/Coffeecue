## 2. SHIPPED (PRs #304–#344, all merged)

  Old orders are marked *estimated*, never silently guessed at.

  distinguishable source from "the cart".

**Reliability**
- **#304 — the self-healing DB connection.** `CoffeeSystem.db` became a
  property that revives a closed connection. This fixed 462 call sites at
  once. It is the single most load-bearing change of the session.
- **#321 — event isolation.** Data cannot leak between events. `check()`
  deliberately **fails OPEN** in three cases (not required / required but
  unset / corrupted) so a config mistake never locks a real queue out.
- **#314 — honest ETAs.** `seconds_per_coffee` takes the MEDIAN GAP between
  completions and ignores gaps > 10 min. Dividing count-by-window cannot tell
  a slow cart from a quiet one; this can.

**Barista floor**

  Covers the STARTED text as well as READY (that was missed once; see §5).

**Customer**

- Wait time is shown as a real number, with a way to say "I have it".

**Display**

## 4. THE EDITABLE-COPY FINDING (read before quoting a language feature)

Steve asked for languages and, separately, for client-facing wording to be
GUI-editable. Audit result: **there is no GUI anywhere for customer wording.**

- `sms_ready_message` / `sms_started_message` exist as backend settings with
  `{name}` `{drink}` placeholders — fully built and **unreachable from the UI**.
- `SMSSettingsPanel.js` looks like the place but edits delivery behaviour and
  writes only to **localStorage** — it never reaches the settings the SMS code
  reads.
- ~125 hardcoded strings in the SMS conversation flow; customer status page
  copy is 100% hardcoded.

Both features need the same migration: customer copy out of the code and into
a keyed catalogue. Do it once. Two cautions Steve must hear first:

1. **Non-ASCII SMS costs ~3x** (UCS-2 = 70 chars/segment vs GSM-7's 160).
   He worked to get SMS to plain ASCII to halve the bill; translated SMS gives
   that back. The web page in other languages is free — the texts are not.
2. **Drink and milk names need a human translator.** A mistranslated milk is
   the wrong coffee, and with lactose and nut allergies that isn't cosmetic.
   Page furniture can be machine-translated; the menu cannot.

## 5. MISTAKES MADE THIS SESSION (so they aren't repeated)

- **TDZ ReferenceError, TWICE.** A hook's dependency array referenced a `const`
  declared further down the file. The build compiled clean both times and the
  page died at runtime — the second one **took `/my` down in production**
  (#343). If you add a hook, check that every name in its dep array is already
  declared above it.
- **#324 broke `/api/display/config`** — a helper was called with a `db` that
  didn't exist in that scope. Every API test passed because screens fell back
  to defaults, so nothing *looked* wrong. Found only by loading the page and
  noticing the SMS number had vanished. **Load the page. Tests alone missed it.**
- **The wrong renderer.** `render_label` drives the Star over CloudPRNT;
  `render_label_png` is the AirPrint path. Layout work must be applied to
  whichever one the real printer uses — check first.
- **`justify-between` does not centre** — it pins to the edges. Centring a
  middle element between two unequal siblings needs `1fr auto 1fr`. Got this
  wrong twice.
- **#336 — server branding had never applied.** The settings-hook merge ran
  *after* the API fetch and overwrote it. Steve's `#ffdeb8` had been silently
  ignored for weeks. I changed the default's value twice before noticing the
  fault was precedence, not the value.
- **Diagnosing print clipping:** the decisive clue was that the printer's OWN
  self-test print was also cut. When the self-test is cut, it is never our
  renderer — it is media alignment.

## 7. STANDING RULES

- Production is **`https://web-production-4cc9c.up.railway.app`**. Not
  `coffeecue-production` — that host does not exist, and probing it produces
  convincing nonsense.
- Merge gate:
  `FAILS=$(gh pr checks N --json state --jq '[.[] | select(.state!="SUCCESS")] | length')`
  — **pending is not success.**
- Verify a deploy by **bundle content**, not hash: grep a marker string out of
  the served JS.
- Always `git checkout -- static/ && git clean -fdq static/` before committing.
- Local dev server on **PORT=5002**. Steve's runs on 5001 — never kill it.
- Bench phones start `+6140000` and are hard-blocked from real SMS. Real SMS:
  max 10, only to Steve's phone.
- Never merge or deploy while Steve is testing, or during an event.
- The printer's root password and the EventsAir client secret must never be
  committed or pasted into chat. They go into the app's own UI.
- Steve is not a coder. Report concisely — he asked for this explicitly.
